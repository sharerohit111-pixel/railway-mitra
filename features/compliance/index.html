BEFORE ADDING ANY DATA

Release checklist

  • Confirm the exact dataset/file/API has an explicit reuse license.
  • Confirm commercial use is allowed if Railway Mitra displays ads or Premium features.
  • Check exclusions: personal data, sensitive data, third-party material, logos and official symbols.
  • Save the original source URL, dataset ID, provider, version/date and a copy or record of the license terms.
  • Display the required attribution and a clear non-endorsement statement.
  • Record the date checked and review again before each major app release.
  • For APIs, verify authentication, rate limits, caching and redistribution terms separately.
