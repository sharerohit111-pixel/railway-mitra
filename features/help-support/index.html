Server & connection problems

Try these steps when a page is slow, not loading, or showing an error.

App is showing a server error or page is not loading
  1. Check that your internet connection is working.
  2. Close and reopen Railway Mitra, then try again.
  3. Wait a few minutes and retry if the issue continues.
  4. If only one feature is affected, open another section to check whether the problem is limited to that page.

Repeated errors may indicate a temporary service or hosting issue. Please try again later.

Page keeps loading or shows a blank screen
  1. Refresh the page once.
  2. Switch between Wi-Fi and mobile data to rule out a network issue.
  3. Close other browser tabs if your phone is low on memory.
  4. Reopen the app after a short wait.
02

App update & display problems

Fix issues where an older screen or layout is still appearing.

I am still seeing the old version of the app
  1. Close Railway Mitra completely.
  2. Open it again while connected to the internet.
  3. If the old version remains, open the website in Chrome Incognito to check the latest published version.
  4. For an installed PWA, open Chrome site settings for Railway Mitra and clear its stored site data only if you are comfortable signing in again.

Clearing site data may remove locally saved app data. Do not do this if you have unsynced records.

Buttons or sections are not responding
  1. Refresh the page once.
  2. Check whether the issue happens in another browser.
  3. Make sure the app has finished loading before tapping again.
  4. Retry after updating the app.
03

Login & account help

Guidance for OTP and Google sign-in.

I did not receive the login OTP
  1. Check that the mobile number is entered correctly.
  2. Confirm that your phone can receive SMS messages.
  3. Wait briefly before requesting another OTP.
  4. Try Google sign-in if it is available to you.
Google sign-in is not working
  1. Check your internet connection.
  2. Make sure Chrome or your browser allows sign-in pop-ups.
  3. Select the correct Google account and try again.
  4. If the error continues, retry after some time.
