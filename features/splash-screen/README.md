# Railway Mitra Splash Screen

This module provides the app's animated opening overlay.

- `splash.css`: scoped visual styling and CSS-only animations.
- `splash.js`: removes the overlay after a short opening sequence.
- The logo is loaded from the existing `assets/icons/icon-512.png`.
- The module is integrated from the root `index.html`; it does not modify app.js, service-worker.js, calculators, or other feature modules.
